# Skills

Cada skill instalada tem sua própria pasta aqui dentro. Coloque os componentes,
exemplos ou código relacionados a cada skill na pasta correspondente.

## Skills disponíveis

- [`gsap-framer-scroll-animation/`](./gsap-framer-scroll-animation) — animações
  de scroll com GSAP ScrollTrigger e Framer Motion (parallax, pin, reveal,
  scroll horizontal, etc).
